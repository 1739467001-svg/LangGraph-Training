# 学习周报（第 1 周）：LangChain / LangGraph 病历智能体实战

> 本周在清洗后的脱敏数据（5 位测试患者）上，从零搭建了「医嘱+检查结果 → 病历文书草稿」
> 的完整 LangGraph 流水线，共 14 节课（正篇 8 + 进阶 6），全程边搭边学。

## 本周完成

- **数据工程**：对 5 名患者的真实病历数据完成脚本化脱敏（两遍扫描 + 模式兜底 +
  反向校验），生成 5 位「测试患者」的干净数据集；日期按天平移到 2099 年，
  保留年龄与全部时间间隔；产出《数据结构报告》
- **LangGraph 核心**：State / Node / Edge、条件边与质控循环（不合格退回重写，
  最多 2 次）、Send 动态并行（38~718 条医嘱自适应 2~40 个工位）、
  interrupt / Command 人工审核中断与恢复、SqliteSaver 持久化检查点
  （跨进程「医生第二天审核」）、子图模块化重构（graph/nodes/state 三件套布局）
- **LangChain 核心**：ChatPromptTemplate、LCEL 链、pydantic 结构化输出合同、
  模型工厂（规则基线 / OpenAI 兼容真模型可切换，含数据外发批准闸门）
- **防编造体系**（本项目核心设计）：每条事实带出处（表名+行号+编号）→
  代码逐字核对（出处存在/药名在原文/剂量数值等价）→ 剔除留痕不静默丢弃 →
  医生审核为最后一道闸 → 自动化评估永不自动批准
- **评估体系**：覆盖率 / 多报 / 编造三指标，对照医生书写的用药记录标准答案，
  5 位患者全量批量验收，自动生成带解读的汇总报告

## 关键数字（批量验收报告 · outputs/批量验收报告.md）

| 指标 | 结果 |
|---|---|
| 用药记录覆盖率 | 33% ~ 80%（5 位患者） |
| 编造进入草稿数 | **0 条**（26 项自动化测试含「说谎模型注入」消防演习保证） |
| 检查所见自覆盖率 | 100%（确定性代码工位） |
| 反复未覆盖药物 | 吸入用七氟烷（5/5）、罗哌卡因（4/5）——麻醉用药不走医嘱表，需接入手术麻醉数据源 |

## 思维收获（写代码之外的）

1. 校验与替换/核对与生成必须同语义；测试锁不变式而非某次输出
2. fail-closed：没验证过的内容不能出口；剔除留痕是审计轨迹
3. 日期平移保留时间关系；统计锚点要防极端值污染
4. 重构只许动结构不许动行为，旧输出是回归基线
5. 「这个栏目需要模型的什么能力」决定上不上模型——检查所见用代码，零幻觉零成本
6. 批准是显式动作（环境变量/医生点击），不是聊天里说一句可以
